# Security Policy

This repository only contains public listing metadata for Chatway's hosted MCP server
(`https://mcp.chatway.app/mcp`). The server itself is operated by Chatway.

## Reporting a vulnerability

Please **do not open a public GitHub issue** for security problems.

Report suspected vulnerabilities in the Chatway MCP server, its OAuth flow, or this listing
privately through the Chatway support team via live chat at
[chatway.app/help](https://chatway.app/help). Include:

- A description of the issue and its impact
- Steps to reproduce, including the MCP client used
- The UTC time of any requests involved

## Revoking access

If you believe an AI assistant's access to your Chatway workspace has been misused, a workspace
owner or admin can disconnect it immediately from **AI → External AI** in Chatway. See
[Manage connections](https://developers.chatway.app/mcp/guides.mcp_manage_connections).
